# État de livraison et améliorations prioritaires

1. Connecter les clés gratuites et vérifier les réponses réelles avec leur couverture : c'est indispensable avant d'affirmer que les cotes ou joueurs fonctionnent.
2. Fournir une interface d'administration authentifiée pour valider les correspondances d'identifiants. Actuellement le schéma et le contrôle existent, mais la saisie reste une opération de maintenance.
3. Activer une collecte planifiée compatible avec l'accès privé ; aucune tâche externe activée. La relecture du calendrier à la consultation est déjà partagée et bornée.
4. Collecter au moins plusieurs centaines de prédictions et de cotes prématch, puis quantifier incertitude/calibration par championnat. Ne pas activer le filtre de value avant validation.
5. Tester l'apport de Dixon–Coles et comparer une baseline de fréquences de ligue à la référence uniforme actuelle. Geler les paramètres avant un nouveau test indépendant.
6. Connecter les apparitions/minutes joueurs et les règles des marchés avant toute estimation buteur/passeur. Ne jamais dériver leur forme récente d'un total de saison.
7. Ajouter ligues progressivement dans `LEAGUES`, avec source, code, saison et licence vérifiés : Portugal/Pays-Bas puis autres divisions/UEFA. Le périmètre actif livré reste les cinq ligues ; ce n'est pas une couverture mondiale.
8. Les API n'ont pas été testées avec secrets réels. Pas de garantie d'absence de restrictions commerciales tierces ni de données manquantes.
9. Les observations sont archivées durablement, mais une politique de rétention/archivage est à dimensionner avant usage public important. Aucun plafond de dépenses d'hébergement n'est garanti par le code.
